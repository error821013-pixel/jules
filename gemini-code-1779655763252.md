# Role: Senior Full-Stack Python Developer & UI/UX Designer

## Task
Develop a full-fledged web application (website) for a computer/gaming club. You need to write both the frontend and backend parts, as well as provide detailed documentation.

## Tech Stack
* **Backend:** Python (FastAPI or Django is recommended).
* **Database:** PostgreSQL.
* **Frontend:** HTML5, CSS3, JavaScript (Tailwind CSS can be used for rapid styling).

## Design Requirements (UI/UX)
* **Color Palette:** Strictly in red, white, and black colors. 
* **Style:** Aggressive gaming aesthetic, yet minimalist and readable. Use a black background as the primary base, white text for readability, and red accents for buttons (Call-to-Action) and important UI elements.

## Main Features and Website Structure
The website must include the following navigation and pages:

1.  **About Us:**
    * Description of the computer club.
    * Photos of the interior and equipment (use placeholders for images).
    * Information about the hardware and peripherals.
2.  **Location:**
    * Club address.
    * Map integration (placeholder for Google Maps API).
    * Contact details and working hours (24/7).
3.  **Personal Account / Profile:**
    * User registration and authorization system (JWT tokens or sessions).
    * Display of the user's current **balance** (in fiat currency).
    * Display of bonus **points** (loyalty system).
    * Visit/booking history.
4.  **Booking — *Integrated into the Profile*:**
    * UI for selecting a date, time, and specific PC (or category: Standard, VIP, Bootcamp).
    * Rental cost calculator based on the selected time duration.
    * A "Book" button that deducts funds from the user's virtual balance.

## Admin Dashboard Requirements
The administrative panel must be protected by authorization and contain the following sections:
* **Current Bookings:** A table displaying a list of currently occupied PCs and the end time of each session.
* **Attendance Analytics:** A chart or table showing the number of unique website/club visitors per day/week/month.
* **Financial Statistics:** Automatic calculation and display of the **average check** (average order value) and total revenue for a selected period.

## Database and Documentation Requirements (MANDATORY)
* Design a database schema for PostgreSQL (Tables: Users, PCs, Bookings, Transactions).
* **Create a `README.md` file**, which MUST include:
    1.  Step-by-step instructions on how to run the project.
    2.  **All raw SQL queries** used by the application (table creation, CRUD operations: adding a user, booking a PC, updating balances, and the specific analytical queries for the admin panel to calculate the average check).

## Output Format
Please provide the code sequentially in the following order:
1.  First, outline the project structure and provide the complete text for the `README.md` file containing all the raw SQL queries.
2.  Second, provide the database connection code and backend models.
3.  Third, provide the routing/controller logic (API endpoints).
4.  Finally, provide the HTML/CSS/JS code for the frontend part (About Us, Location, Personal Account with Booking, Admin Dashboard), strictly adhering to the red-white-black color scheme.
